# 💰 Simple Cash App UI Prototype (Android - Kotlin + XML)

## 📌 Project Overview
The Simple Cash App UI Prototype is a beginner-friendly Android application developed using Kotlin and XML. It simulates a basic banking interface with a login screen and OTP verification using Toast messages.

This project is frontend-only and does not include backend or database functionality.

---

## ✨ Features
- Login screen (UI-based authentication simulation)
- Fake OTP verification using Toast message
- Navigation from login to dashboard
- Static cash dashboard interface
- Deposit and Withdraw buttons (UI only, no real logic processing)

---

## 🛠️ Technologies Used
- Kotlin (Application logic)
- XML (User Interface design)
- Android Studio (Development environment)

---

## 🎯 Purpose of the Project
This project was created for academic purposes to demonstrate:
- Android UI design using XML
- Kotlin event handling
- Activity navigation
- Frontend-only application flow
- Basic simulation of authentication process

---

## ⚠️ Limitations
- No backend or database integration
- OTP is simulated using Toast only
- No real authentication system
- Balance is static and not functional
